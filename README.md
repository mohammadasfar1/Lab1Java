a small java app to practice on oop principles
---
# how to use it?
1.open the repo
2.download the files
3.open your editor and drop the file
4.then run it
---
## what is the purpose of this project?
this project aims to practice on the basic OOP principles, and how you can use those principles to design a good app

## what is this project
a mini project of a company selling smart devices

## Classes used
1. Company (The main class)
2. SmartDevice (abstract class)
3. SmartFan (child of SmartDevice)
4. SmartCamera (child of SmartDevice)
5. SmartLight (child of SmartDevice)
6. WiFi SmartCamera (a child of SmartCamera)
7. WiFi SmartLight (a child of SmartLight)
8. WiFi SmartFan (a child of SmartFan)
9. WiFiConnection (an interface for all classes that connect a WiFi)
